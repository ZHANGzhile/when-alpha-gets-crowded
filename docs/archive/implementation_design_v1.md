# When Alpha Gets Crowded：报告理解与实施设计

日期：2026-09-05。依据：本地《When Alpha Gets Crowded.pdf》，58 页、85 节。

状态：设计建议，尚未冻结为研究协议；未下载研究数据、未实现研究引擎、未运行实证实验。原目录仅有报告及 Git 元数据。下文区分报告规定与需要补充的实施决策，不能把任何预期当成结果。

## 1. 我对项目的理解

研究单位是 factor × week，研究对象是既有选股信号的可靠性。股票日频数据只是底层输入。

核心问题是：用公开市场数据构造的潜在因子拥挤代理，能否在市场状态与因子自身状态之外，增量预测未来因子脆弱性？

这包含三个不同的证据层次：

1. 测量：真实因子组合相对结构匹配的随机组合，是否有特殊的收益同步、异常交易、流动性变化和持仓交集？
2. 预测：这些迹象是否在未来收益、左尾、回撤或信号失效上提供样本外信息？
3. 应用：只用样本外预警调整因子暴露，是否在成本与公平风险基准下仍有价值？

即使全部通过，也只能支持“与潜在拥挤一致的市场迹象具有预测价值”，不能证明实际机构持仓拥挤，更不能推出因果关系。

报告是研究任务书，不是已有结果报告。其 Figure 1–13、Table 1–11 都是拟交付要求，没有回归结果、模型分数或实际净值。

## 3. 实施前必须解决的定义问题

### 3.1 接口参数不等于历史数据已经可靠

报告选用 BaoStock，但当前尚未实际验证接口完整性。必须先抽样验证历史指数成分、行业分类、PB、复权、停牌、ST 和退市证券覆盖。

成分记录至少区分 requested_date、effective_date、source_update_date、available_at、retrieved_at。行业与财务记录同样处理。下载时间不能被伪装成历史发布时间；无法确定 available_at 时，要保存来源和推断规则。

抽样覆盖早期年份、样本调整前后、分红除权、停牌复牌、行业变更与退市。检查历史查询是否真的随日期变化，且返回的生效日期不晚于所查询时点。

数据不合格时先更换或补足来源；无法修复则在查看测试结果前缩短研究区间或降低研究结论范围。不得用今天的成分或行业分类补回历史。

### 3.2 三个时间不能合成一个 date

明确 decision_at、execution_at、label_end_at：

- 周末信号必须等价格、成交及估值等输入全部可得后才成立；最早在下一交易日执行。
- 理论因子收益可以保留报告的次日收盘到收盘收益口径，但这是带有理想成交假设的研究序列，不能直接当作可交易业绩。
- 应用回测建议下一交易日开盘调仓，首日新持仓仅获得开盘至收盘收益；原持仓在成交前承担隔夜收益。
- 执行引擎负责拒绝或延迟无法成交的订单，记录目标权重、实际权重及偏差。仅靠日线不能证明实际开盘可成交，因此结果应称日频执行近似。

两类收益使用独立字段，标签与实验元数据声明引用哪一类。主研究复制报告口径；应用结论来自独立执行账本，不把理论收益搬过去。

### 3.3 252 个交易日不等于 252 条周频记录

个股换手等原料按日频滚动；factor × week 指数按周频输出。周频特征标准化建议取过去 252 个交易日内的历史周末观测，约 50 个点，排除当前点，最低 40 个有效观测。不得对周表直接 rolling(252) 后称其为“一年”。

建议明确区分 calendar_window_trading_days、min_observations 和 sample_frequency，停止使用含糊的单一 window 参数。

### 3.4 有效样本起点应由依赖计算

如果 2012 年开始原始行情，12-1 动量通常到 2013 年左右才具备完整信号。若 Crash 阈值还要求三年因子历史，完整的主标签样本可能约从 2016 年开始，而不是报告举例的 2013–2014 年。

数据引擎输出每一因子的首个信号日、首个拥挤指数日、首个阈值可用日与最终可训练日期；不得用缩短窗口偷偷补早期样本。

截至 2026-08-31 尚未走完未来 20/60 个交易日的样本可以生成当前特征和预测，但对应标签必须为空。不同期限分别判断成熟，不要因为 60 日标签缺失而丢掉有效 20 日样本。

### 3.5 行业去均值不是彻底去除市场暴露

报告的“个股收益减同行业中位数”可作透明主口径，但不能声称已消除全部市场和行业风险。个股 beta 不同、行业样本较少等仍会影响同步性。

主版本保留原定义；行业基准尽量排除股票自身；记录小行业回退情况。必要的稳健性版本使用只根据过去估计的市场/行业 beta 残差。任何残差方法都要对真实组合和 placebo 同样处理。

### 3.6 组合重叠不是外部资金拥挤的直接测量

四个固定因子选到相同股票，可能只是价值、低波等特征本身的关系。它不能说明市场上使用策略的投资者变多。

原始 Jaccard 保留为“因子组合结构重叠”。补充匹配置换下的超额重叠。只有四个节点，普通网络密度可能长期等于 1，应以平均/最大边权、加权度和超额重叠为主要统计量。不能仅凭四节点图宣称结构创新或完成拥挤识别。

## 5. 因子引擎

按报告保留四个定义：MOM = P[t-21]/P[t-252]-1；REV = -(P[t]/P[t-20]-1)；LOWVOL = -Std(r[t-59:t])；VALUE = -log(PB)，且 PB > 0。

收益类信号使用经公司行为核验的收益序列。交易金额与流通市值计算使用对应实际价格，不混入任意归一化后的复权价格。

若来源确认 volume 单位为股、turn 为百分数，则 float_shares = volume/(turn/100)。turn 为零、缺失或异常时不计算该值；不能用除以极小常数制造巨大市值。该估计仅在抽样验证后用于 size 匹配。

排序顺序：历史成分 → 当时可知过滤 → 因子原值 → MAD 处理 → 行业内排名 → 合并选择前后 10%。保存原值，规定并列排序、取整规则和小行业回退。行业内排名只能降低行业倾斜，不能自动保证严格行业权重中性；输出行业暴露诊断，严格中性版本另作稳健性。

每个 leg 初始等权，周内持仓权重随收益漂移。不得用每日简单平均收益无意实现“每日重平衡”。周中停牌股票保留持仓和可得估值，不能因为无法交易而删除；退市损失不能在样本中消失。

Long - Short 研究序列应注明例如每单位研究资本对应 +1 多头、-1 空头的名义约定，并保持净值、波动与换手口径一致。此约定不等于已建成可融资、可借券的投资组合。

## 6. 拥挤特征引擎

每个 t 固定当时的 long/short 股票集合，读取这些股票截至 t 的历史 60 日等窗口。这里用当时已知成员回看其历史是合法的；不能读取 t 之后成员或行情。行业归属与市场基准则按历史日 d 的可知记录处理。

| 特征 | 主版本 | 关键边界 |
| --- | --- | --- |
| 收益同步 | 行业残差相关矩阵的非对角均值 | long/short 分开；小样本和零方差有标记 |
| 特征值集中 | 最大特征值 / trace(C) | 用合法半正定相关矩阵；真实组与 placebo 同估计器 |
| 异常换手 | 当前换手相对过去 60 日中位数/MAD | 基线不包含当天；MAD=0 记无效，不输出无穷大 |
| 换手同步 | TurnoverZ > 1.5 的股票占比 | 分母仅含有效观测，并报告有效覆盖率 |
| 流动性压力 | 20 日均值的 abs(return)/amount，再相对自身过去标准化 | amount=0 不是无限压力，也不能当作正常零值 |
| 跨因子重叠 | 多头 Jaccard 的跨因子均值 | 原始与匹配超额版本并存 |

建议 ILLIQ20 自身基线取此前 252 交易日，至少 126 个有效值；这一点报告未明确，必须写进协议。换手的 raw MAD 是否乘 1.4826 也要固定，主版本按原公式使用 raw MAD，否则阈值 1.5 的含义改变。

60 日约 80 只股票的矩阵天然秩不足，最大特征值仍可算，但估计噪声大。不需要为了可逆而求逆。主估计器可采用事先约定的收缩相关矩阵，并保留样本相关矩阵稳健性结果；pairwise 缺失拼接可能不半正定，不能直接拿它算谱集中度而不检查。

匹配随机组合：同一日期、同一股票池、相同股票数，匹配行业与滞后流动性；size 通过校验时才加入。流动性匹配建议使用截至 t-20 的历史水平，避免用当前流动性恶化把待测信号一并匹配掉。精确回看长度和匹配层级须预先固定。

主版本 B=100，每次抽样无放回；不同重复可重用股票。记录交集及匹配误差。不能满足匹配时按预先写好的层级合并分组并标记，不能静默降级。主版本从全体合格股票抽取，不强制排除真实因子成员；排除版本可作敏感性。

每个特征同时保存 raw、actual - placebo_mean，以及标准差非零时的 placebo_z。主合成指数建议对六类特征的超额版本再做过去一年标准化并等权平均；这是对报告混合 raw/excess 定义的明确化，应同时保留报告原始混合版本用于核对。缺项不随意改分母，未满足主特征集合时指数记缺失。

PCA 是次级分析：仅在训练期拟合，符号用预先规定的锚点对齐，载荷无共同方向时不称其为拥挤状态。

计算优化优先缓存日频残差及周度窗口矩阵，再复用真实组合和 placebo 子矩阵；按日期批处理。不把全部 placebo 股票明细常驻内存。先完成少量日期的数值对照，再扩大规模。

## 7. 标签引擎

主标签沿用报告的动态因子策略未来收益；即未来每周仍按既定规则调仓。它回答“当前状态能否预测策略未来表现”。同时补充固定 t 时点成员不变的 20 日组合结果，检验当前 footprint 与当前成员风险的对应关系；两者不能混称同一个问题。

历史 Crash 阈值建议明确为：取截至 t 的过去 756 个交易日内，已经完成的历史 20 日持有期收益，再算 10% 分位数。任何起点 s 的历史窗口均须满足 s+20 <= t。要求完整历史预热。实际事件比例随状态变化，不保证每年恰好 10%。

报告的 Future MDD 需要补上 NAV[0]=1；峰值计算包含初始点，防止第一日损失不被算作回撤。建议输出非负损失幅度，另存原报告负值口径以便核对。

RankIC 的定义固定为各周信号与其随后一周股票收益的 Spearman 相关，未来四周平均用于 signal breakdown。四周在节假日下不一定等于 20 个交易日，保存实际时间范围，命名为 future_ic_4w。它与单次 t 信号预测未来 20 日收益的 IC 分开。

## 8. 验证设计

### 主比较与模型

保持报告的 A–E 五个模型。决定性检验是 D（市场 + 因子状态）与 E（D + 拥挤）的同样本、同时间划分、同调参预算比较。D 不含拥挤，不能让缺失处理使 D/E 使用不同样本。

均值用 OLS/稳健回归；左尾用 10% 分位数回归；Crash 用正则化 Logistic。先检验简单合成指数，再进行受控的分项特征实验。市场与因子状态各个回看长度必须在协议中明确。

建议把样本外 Log Loss 改善设为主概率预测指标；PR-AUC 与最高风险 10% 状态的实际事件率设为关键辅助指标。Brier、ROC-AUC 和校准曲线完整报告。分类加权不是必选默认，因为它会改变概率含义；未加权正则化 Logistic 为主，加权模型须用自然事件比例的历史验证数据校准。

### 时间划分

保留 expanding walk-forward，但所有实验规则先在开发期确定。建议将 2020–2023 用于开发期走步评估，将 2024–2026-08-31 保留为最终评估区间；精确可用训练起点由数据预热决定。

最终区间可以执行预先规定的年度扩展重训，允许使用当时已成熟的早期年份标签，但不允许观察结果后改特征、超参数空间或控制规则。最终评估前先锁协议哈希。

每个 fold 保存实际标签区间。训练标签结束时间早于验证首个决策时刻；验证标签不能延伸到测试开始。Purge 基于区间重叠判定，不能只比较 train_date < test_date。20 日主任务按 20 日标签清除，60 日任务按其自身区间处理。

标准化、缺失填补、PCA、模型和概率校准均在对应历史段拟合。样本外分位分组边界也只来自过去；全样本分箱可用于描述图，但不能被称为可执行分组。

### 推断与证伪

每因子周序列用适当 HAC；跨因子比较使用按连续日期块重采样且保留四个因子的联合结构的 bootstrap。只有四个因子，不能依赖“四个因子簇”的普通聚类标准误。

主 bootstrap 可预设 13 周块长，8/26 周作敏感性；对 D/E 指标差做成对重采样。20 日重叠标签与同一次危机不会被当成独立事件。另报告合并后的风险事件段数量。

匹配随机组合有两种用途，不能混淆：一是同期特征校正，二是完整随机策略产生自己的未来标签并走完预测评估。后者才能检验预测能力是否只是一般市场结构。

行业内打乱排名应完整重算成员、特征、标签；尽量匹配换手和持有期，避免随机组合更换频率不同导致伪比较。时间错位检验保留连续块和因子间依赖，不进行逐行 IID shuffle。

分别报告因子与多空腿，做特征消融和报告规定的窗口、阈值、股票池等稳健性。主假设与探索性实验分开，探索结果处理多重比较，并展示失败组合。

## 9. 控制器：检验“在什么时候减仓”的价值

仅使用 oos_predictions。主应用沿用 long-only 主动倾斜：组合 = w × 因子多头 + (1-w) × 基准。

这里减小 w 是减少因子相对基准的主动暴露，不等于减少整个账户的股票市场仓位。因此同时报告总收益风险与相对基准的主动收益风险。

报告中的 clip(1-p, 0.25, 1) 可作为预先规定的主规则。0.3/0.6/0.8 的示例阈值未必适合约 10% 基准发生率，不能直接假定会触发；分层方案若采用，阈值仅由开发期确定。

至少比较五种控制策略：

1. 满主动暴露。
2. 固定较低主动暴露；权重在历史开发段确定并报告测试期实际均值。
3. 波动率控制。
4. 仅使用市场 + 因子状态模型 D 的风险控制。
5. 加入拥挤模型 E 的控制。

另可用与最终主动仓位均值相同的固定暴露做事后归因图，但必须标注其非事前可执行基准。

只有 E 在公平基准与交易成本下仍有改善，才能支持拥挤信息具有应用价值；相对满仓回撤下降本身不够。

CSI800 指数收益只是基准，不自动等于可成交资产。应用版需明确基准复制篮子或历史可用的跟踪工具；未完成这一步只能称“理想化基准配置实验”。

成本按每笔实际单边交易名义金额计算，完整换仓的买入与卖出均收费，不混淆 half-L1 换手与双边成交额。5/10/20 bp 是报告要求的敏感性假设，不能宣称代表所有年份的实际费税。若要声明净实盘可行，另核验历史费税、滑点、涨跌停和交易规则。

最先实现的单元与集成检查：未来数据扰动不影响历史特征；历史成分 as-of 连接；周频一年窗口；权重漂移；停牌持仓连续；除权收益；第一日下跌的 MDD；尾部阈值只读成熟历史收益；按标签区间 purge；训练/校准均不触及未来；执行成本按实际成交收费。

## 11. 最终结果怎样判断

工程成功：给定固定源数据快照、代码和配置，可以重建数据表、模型预测和图表。

研究成功：清楚回答增量预测是否存在、来自哪类 footprint、在哪些因子成立，以及 placebo 是否推翻解释。没有显著性也是合法结果。

应用成功：控制器对风险改善的贡献超过简单降低暴露、波动控制和普通风险预测，并且成本后仍有经济意义。研究成功不保证应用成功。

优先级应是：时间与数据正确性 → 可证伪比较 → 稳健结果 → 应用价值 → 更复杂模型。
